## Estado

Línea base completa de la demo Vite trasladada a `C:\Codex\GET`.

- Viewport de escritorio: `1440 × 900`.
- Viewport móvil: `390 × 844`.
- Capturas: viewport visible, sin composición ni modificación de la demo.
- Temas: claro y oscuro mediante el control visible de la aplicación.
- Total: 44 archivos PNG.
- Pantallas pendientes: ninguna.

La demo fue servida temporalmente por Vite en la red local para que el navegador automatizado pudiera acceder desde su entorno aislado. No se modificaron `index.html`, `src/main.js`, `src/styles.css`, `vite.config.js` ni `netlify.toml`.

Las medidas anteriores fueron aplicadas mediante el control de viewport del navegador. El navegador integrado rasteriza únicamente su área de contenido y descuenta chrome interno, scrollbar y escala del sistema; por esa razón algunos PNG tienen dimensiones físicas menores. No se reescalaron ni rellenaron las imágenes, para evitar deformar la referencia visual.
