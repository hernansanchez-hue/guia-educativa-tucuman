Por esa excepción externa se validaron las dos evidencias mínimas Next.js: escritorio claro 1440×900 y móvil claro 390×843. La carrera es `higiene-y-seguridad`; la offering es `universidad-siglo-21-concepcion-higiene-y-seguridad`; no tiene WhatsApp propio y usa el fallback institucional.

Lint, build, HTTP y la reutilización de plantilla completan la validación restante. Esta excepción no representa un defecto de GET.
