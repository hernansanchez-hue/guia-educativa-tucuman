      Objetivo comercial                                                          
      Este documento no es una guía para estudiantes: es una base de trabajo para que GET identifique instituciones, ubique datos de contacto y
      organice la prospección. Las sedes privadas aparecen como prospectos comerciales directos. Las estatales se incluyen para construir
      cobertura provincial, legitimidad, alianzas, perfiles gratuitos y difusión de su oferta.

      Criterio de inclusión y lectura                                             
      Se incluyen las sedes con oferta activa de nivel superior no universitario (SNU, SNU-INET o cursos SNU) en el Padrón Oficial de
      Establecimientos Educativos. Cada anexo se conserva como punto territorial independiente. Las carreras solo se consignan cuando fueron
      publicadas por INFoD o por una fuente institucional; si no aparecen, se marca como pendiente de relevamiento. Los teléfonos, correos y
      domicilios pueden requerir una validación breve antes del contacto comercial.
