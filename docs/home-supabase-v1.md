# Home Supabase v1

Home conserva hero, video, copy, CTA, animaciones y estilos editoriales. El único catálogo consumido es la lista de ciudades de `CitySelector`; ahora llega desde `home-catalog.js` con source local por defecto o Supabase con ISR 60. No usa instituciones destacadas, carreras ni ofertas. UUIDs no llegan a UI; los slugs se preservan. La comparación local/Supabase de las ciudades es equivalente y una ciudad publicada futura aparece tras el TTL, aunque la navegación actual del selector conserva su comportamiento canónico. Supabase remoto, multimedia y CSS no fueron modificados.
