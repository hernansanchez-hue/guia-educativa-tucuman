# Reglas permanentes del proyecto GET

- La demo existente es la fuente de verdad visual.
- Se debe conservar toda su apariencia.
- No rediseñar.
- No eliminar ni reemplazar textos.
- No simplificar secciones.
- No cambiar colores, tipografías, tamaños, proporciones ni responsive.
- No conectar Supabase hasta que la migración visual a Next.js esté validada.
- No migrar todo en una sola tarea.
- Analizar antes de modificar.
- Informar previamente qué archivos serán modificados.
- Realizar validaciones después de cada cambio.
- Informar todos los archivos creados o modificados.
- Detenerse al finalizar cada etapa.
- No avanzar automáticamente a la siguiente etapa.
